# Bike Buyers Analysis: Excel Dashboard

An Excel project that analyzes 1,000 customers to understand who buys bikes, using PivotTables, charts and slicers.

## Tools
- Microsoft Excel: formulas, PivotTables, charts, slicers

## Dataset
- File: `Excel_Project_Dataset.xlsx` (1,000 customers)
- Columns: ID, marital status, gender, income, children, education, occupation, home owner, cars, commute distance, region, age, purchased bike
- Added an **Age Brackets** column with an `IF` formula: Adolescent (under 31), Middle Age (31-54), Old (over 54)

## What I did
1. Cleaned and prepared the data
2. Created age brackets with an `IF` formula
3. Built PivotTables for average income, commute distance and age
4. Added charts and slicers for an interactive dashboard

## Key findings
- 481 of 1,000 customers (48.1%) bought a bike
- Middle-aged customers (31-54) made up about 80% of buyers (383 of 481)
- Customers with a 0-1 mile commute were the largest buyer group (200 buyers)
- Only about 30% of customers commuting more than 10 miles bought a bike
- Buyers earned more on average ($57,963) than non-buyers ($54,875)

## Business insight
Marketing should target middle-aged customers with short commutes, where purchase rates are highest.
